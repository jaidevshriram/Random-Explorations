Bulldozer Part Inspector

The NeRF Lego bulldozer (train/r_19) rebuilt as semantic vector parts. Hover the image or the tree to see what each region is; click to pin it.

Scroll or pinch to zoom, drag to pan, double-click to reset. Errors are RMSE in 0–255 levels over the pixels a part actually shows.

Semantic tree

object › material › shade › part. Tick boxes hide or show a branch. RMSE is per visible pixel; share is that branch's part of the total squared error.
